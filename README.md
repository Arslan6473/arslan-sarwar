# 💼 Personal Portfolio Web App

This is a modern and responsive personal portfolio web application built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. It showcases your skills, projects, experience, and contact information in an elegant and interactive way.

## 🚀 Tech Stack

- **Next.js** – React framework for production with server-side rendering and routing
- **TypeScript** – Strongly typed language for safer, scalable code
- **Tailwind CSS** – Utility-first CSS framework for rapid UI development
- **Framer Motion** – Animation library for React to add smooth transitions and motion effects

## 📸 Features

- Responsive design for desktop, tablet, and mobile
- Smooth page transitions and animations
- Sections for About, Skills, Projects, and Contact
- Easily customizable content and theme
- SEO optimized with custom `<Head>` tags

## 🛠️ Getting Started

### Prerequisites

- Node.js (v16 or above)
- npm
